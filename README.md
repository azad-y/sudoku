# سودوکوی حافظه

بازی سودوکوی ساده برای تمرین تمرکز و حافظه. با HTML و JavaScript خالص نوشته شده، بدون هیچ وابستگی، و به‌صورت PWA روی گوشی نصب می‌شود و آفلاین کار می‌کند.

## امکانات

- سه سطح: آسان، متوسط، سخت (هر معما جواب یکتا دارد)
- **حالت حافظه:** چند ثانیه اعداد را می‌بینی، بعد بخشی از آن‌ها پنهان می‌شود و باید از حافظه پرشان کنی
- یادداشت‌گذاری، برگشت، پاک‌کردن و راهنما
- آمار روزانه، روزهای پیاپی و بهترین زمان هر سطح (ذخیره در مرورگر)
- تم روشن و تیره، متناسب با تنظیم گوشی

## اجرا

نیازی به نصب یا build نیست. `index.html` را در مرورگر باز کن.

برای نصب به‌عنوان اپ، فایل‌ها باید از آدرس HTTPS سرو شوند (مثلاً GitHub Pages). بعد در Chrome گوشی: منو ← **Install app**.

## انتشار با GitHub Pages

1. **Settings ← Pages**
2. Source: **Deploy from a branch**، شاخهٔ `main` و پوشهٔ `/ (root)`
3. آدرس سایت: `https://USERNAME.github.io/REPO/`

## ساختار فایل‌ها

| فایل | کار |
| --- | --- |
| `index.html` | بازی (HTML، CSS و JS در یک فایل) |
| `manifest.webmanifest` | اطلاعات نصب اپ |
| `sw.js` | کش برای کار آفلاین |
| `icon-192.png`، `icon-512.png` | آیکون اپ |

## نکته برای آپدیت

بعد از تغییر فایل‌ها، عدد نسخه در `sw.js` (`CACHE = 'sudoku-hafeze-v1'`) را بالا ببر تا گوشی نسخهٔ جدید را بگیرد.
